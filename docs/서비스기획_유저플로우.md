# 습관 미션 앱 - 서비스 기획 및 유저플로우

## 1. 서비스 개요

한 줄 소개: 부모의 잔소리를 아이의 게임으로 바꾸는 습관 형성 앱

- 대상: 유치원 ~ 초등 저학년 아이와 부모
- 핵심: 아이가 생활습관 미션을 하면 포인트를 받고, 부모와 함께 정한 보상을 엄마/아빠에게 직접 신청한다.
- 차별점
  - 아이는 기다리지 않고 즉시 칭찬을 받는다.
  - 부모는 하루 한 번만 확인한다.
  - 보상을 아이가 함께 정하고 직접 신청한다.

## 2. 핵심 개념

| 개념 | 설명 | 예시 |
|---|---|---|
| 미션 | 부모가 등록하는 생활습관 | 양치하기 +50 |
| 포인트 | 미션 완료 시 즉시 획득. 대기 / 확정으로 구분 | 대기 130 / 확정 1,050 |
| 승인 | 부모가 하루 한 번 일괄 확인 | 저녁에 승인하기 |
| 보상 | 부모와 아이가 함께 정하고 필요 포인트를 지정 | 장난감 = 1,000 |
| 신청 | 포인트가 모이면 아이가 엄마/아빠에게 요청 | 장난감 -> 엄마 |
| 펫 | 미션을 할수록 성장하는 캐릭터 (게임 요소) | Lv.3 |

## 7. 첫 사용 흐름 (온보딩)

```
가입 --> 아이 프로필 (이름, 나이) --> 펫 고르기 --> 추천 미션 고르기
     --> 보상 함께 정하기 --> 부모 PIN 설정 --> 아이 모드로 기기 전달
```

- 추천 미션 템플릿(양치, 정리, 인사, 옷 입기, 밥 먹기)을 제공해 1~2분 안에 설정 완료

### 포인트 상태

```
미션 완료 --> [대기] --부모 승인--> [확정] --보상 지급--> [차감]
                 |
                 +--부모 반려--> [취소]
```

### 신청 상태

```
[보냄] --> [확인중] ("나중에 줄게" + 한마디) --> [받음] (포인트 차감)
   |                                              ^
   +------------------ "지금 줬어요" -------------+
```

### 규칙

- 신청은 확정 포인트가 충분할 때만 가능 (대기 포인트는 제외)
- 포인트는 실제 보상 지급 시 차감, 남은 포인트는 이월
- 펫 레벨은 누적 미션 횟수 기준 (포인트를 써도 레벨은 유지)
- 미션별 하루 인정 횟수로 반복 체크 방지
- 반려는 "다시 해보자" 같은 부드러운 문구로 표시
- 부모 알림은 저녁 요약 1회와 보상 신청 시에만 발송

## 9. 해커톤 MVP 범위

| 구분 | 포함 | 나중에 |
|---|---|---|
| 아이 | 홈, 오늘의 미션, 양치 미니게임, 포인트 획득, 내 보상, 보상 신청, 신청 완료, 보상 받음 | 신청 현황 화면 (홈 배지로 대체), 펫 꾸미기 |
| 부모 | PIN, 부모 홈, 오늘 한 일, 보상 신청 처리, 미션 등록, 보상 등록 | 리포트, 형제 여러 명, 녹음 |
| 공통 | 모드 선택, 간단 온보딩 | 실제 송금, 사진 인증 |

## 10. 시연 시나리오 (3분)

1. 부모가 미션 "양치하기 +50"과 보상 "장난감 1,000"을 등록한다.
2. 아이 모드로 전환해 양치 미니게임을 하면 즉시 +50과 펫 성장 연출이 나온다.
3. 부모 모드에서 "오늘 한 일"을 일괄 승인한다.
4. 포인트가 다 찬 상태에서 아이가 엄마에게 장난감을 신청하면 편지 배달 연출이 나온다.
5. 부모가 "지금 줬어요"를 누르면 아이 화면에 축하 연출이 나온다.
