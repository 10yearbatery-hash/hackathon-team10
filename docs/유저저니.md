# 유저 저니

누가, 언제, 어떤 화면을 보는지를 그림으로 정리한다. 규칙과 용어는 `docs/서비스기획.md`가 기준이다. 화면 ID는 이 문서가 기준이다.

> 글꼴에 따라 한글 폭이 달라 테두리가 약간 어긋나 보일 수 있다.
> (가정)은 사용자가 말하지 않아 정리하면서 정한 것, (미정)은 아직 답을 받지 못한 것이다.

화면 ID: S = 공통, A = 아이 폰, P = 부모 폰

## 4. 인증 한 건이 지나가는 길

아이 폰, 서버(Supabase), 부모 폰이 어떻게 주고받는지 보여준다.

```
 아이 폰                 서버                     부모 폰
 -------                 ----                     -------
 1. 미션 선택
 2. 촬영 (캐릭터 반응)
 3. 제출 ---------------> 4. 사진/영상 저장
                             상태: 확인 대기
 5. 즉시 축하 연출
    마디 한 칸 전진
    (확인 대기 표시)
                             6. ---------------> 7. 앱을 열면
                                                    "대기 1건" 표시
                                                 8. 인증 확인 화면에서
                                                    사진/영상 보기
                                         +----- 9a. 승인
                                         |       9b. 반려
                             10. 상태 변경 <----+
 11. 앱을 열면 반영
     9a 승인: 마디 확정
     9b 반려: 캐릭터 한 칸 하강
              "다시 해보자"
```

- 5번은 서버 응답을 기다리지 않고 바로 보여준다. 아이가 기다리지 않는 것이 핵심이다.
- 11번의 반영 시점은 아이가 앱을 열었을 때다. 실시간 반영은 시연 때 필요하면 추가한다. (가정)

## 5. 촬영 화면 연출 후보 (미정)

인증하는 동안 캐릭터가 지켜보는 느낌을 어떻게 줄지 정해야 한다. 아래는 후보이고, 시연에서 가장 눈에 띄는 하나를 골라 거기에 집중하는 방식을 권한다.

```
 후보 1: 위아래 반반            후보 2: 캐릭터가 화면 위를 돌아다님
+------------------+          +------------------+
|                  |          |        [캐릭터]  |
|   카메라 화면    |          |   카메라 화면    |
|                  |          |  [캐릭터]        |
+------------------+          |                  |
|    [캐릭터]      |          |                  |
|   (쳐다본다)     |          +------------------+
+------------------+

 후보 3: 촬영 순간에 반응
+------------------+
|   카메라 화면    |        [촬영 버튼] 누르기 전: 두리번
|                  |        [촬영 중]         : 눈을 크게 뜸
|  [캐릭터 모서리] |        [촬영 끝]         : 환호
+------------------+
```

### 아이 폰

원칙: 글씨 최소화, 그림과 큰 버튼 중심. 아이가 조작할 것은 최소로 한다.

#### A1. 길 홈 - 내 위치와 다음 상자를 한눈에

아래에서 위로 올라가는 세로 길이다. 지금은 확정 8칸에 확인 대기 1칸이 있다.

```
+--------------------------------+
|  챕터 1  숲속 마을      8 / 10 |
+--------------------------------+
|                                |
|            +--------+          |
|            | 보물   |          |
|            | 상자   |          |
|            +--------+          |
|            (잠김  10)          |
|                |               |
|        ( 확인 대기  9 )        |
|          [캐릭터]              |
|           /                    |
|    ( 완료  8 )                 |
|           \                    |
|        ( 완료  7 )             |
|            |                   |
|        ( 완료  6 )             |
|            |                   |
|           ...  (위로 스크롤)   |
+--------------------------------+
| +----------------------------+ |
| |   오늘 미션 하러 가기  2/5 | |
| +----------------------------+ |
+--------------------------------+
```

- 위쪽 숫자(8 / 10)는 확정된 마디 수다. 확인 대기 마디는 포함하지 않는다.
- 캐릭터는 확정 마디와 확인 대기 마디를 합친 위치에 서 있다.
- 확인 대기 마디는 완료 마디와 모양이 다르다 (색이 연하거나 점선). (가정)

```
| +----------------------------+ |
```

### 부모 폰

원칙: 빠른 확인과 처리, 처리할 일이 맨 위

#### P1. 가족 만들기

```
+--------------------------------+
| <  가족 만들기                 |
+--------------------------------+
|                                |
|  아이 이름                     |
|  [ 하늘                      ] |
|                                |
|  +--------------------------+  |
|  |         만들기           |  |
|  +--------------------------+  |
|                                |
|  ----- 만든 뒤 -----           |
|                                |
|  아이 폰에서 이 숫자를         |
|  입력해 주세요                 |
|                                |
|       [ 4 7 2 9 1 3 ]          |
|                                |
+--------------------------------+
```

#### P2. PIN 입력

```
+--------------------------------+
| <  부모 모드                   |
+--------------------------------+
|                                |
|      비밀번호를 입력하세요     |
|                                |
|          (o) (o) ( ) ( )       |
|                                |
|        [1]   [2]   [3]         |
|        [4]   [5]   [6]         |
|        [7]   [8]   [9]         |
|              [0]   [<]         |
+--------------------------------+
```

#### P3. 부모 홈

```
+--------------------------------+
| 하늘이                  [설정] |
+--------------------------------+
|  챕터 2  바닷가 마을           |
|  [###-------]       3 / 10     |
|                                |
| +----------------------------+ |
| | [!] 확인할 인증 2건        | |
| | 양치하기, 비타민 먹기      | |
| |                [확인하기]  | |
| +----------------------------+ |
| +----------------------------+ |
| | [상자] 열린 상자 1개       | |
| | 챕터 1 보상: 아이스크림    | |
| |                [줬어요]    | |
| +----------------------------+ |
|                                |
| +----------+ +----------+      |
| | 미션     | | 보상     |      |
| | 선택     | | 설정     |      |
| +----------+ +----------+      |
+--------------------------------+
```

#### P4. 인증 확인 - 건별로 하나씩

```
+--------------------------------+
| <  인증 확인               1/2 |
+--------------------------------+
|  양치하기          오늘 08:10  |
|                                |
|  +--------------------------+  |
|  |                          |  |
|  |      [ 영상 재생 ]       |  |
|  |         ▶  0:18          |  |
|  |                          |  |
|  +--------------------------+  |
|                                |
|  +------------+ +------------+ |
|  | 다시 해보자| |    승인    | |
|  +------------+ +------------+ |
|   반려하면 아이 캐릭터가       |
|   한 칸 내려와요               |
+--------------------------------+
```

- 사진 미션은 영상 자리에 사진이 들어간다.
- 승인하거나 반려하면 다음 건으로 넘어간다. 마지막 건을 처리하면 부모 홈으로 돌아간다. (가정)

#### P5. 미션 선택

```
+--------------------------------+
| <  미션 선택                   |
+--------------------------------+
```

## 7. 상태별 화면 변화

한 건의 인증이 지나가는 동안 두 화면이 어떻게 달라지는지 정리한다.

| 시점 | 아이 폰 (A1 길 홈) | 부모 폰 |
|---|---|---|
| 인증 전 | 캐릭터가 확정 마디 위에 서 있다 | 변화 없음 |
| 제출 직후 | 캐릭터가 한 칸 전진, 새 마디가 "확인 대기"(연한 색) | 앱을 열면 "확인할 인증 +1" |
| 부모 승인 | 확인 대기 마디가 "완료"로 바뀐다 | 해당 건이 목록에서 사라진다 |
| 부모 반려 | 캐릭터가 한 칸 내려오고 A8 "다시 해보자" 안내 | 해당 건이 목록에서 사라진다 |
| 챕터 끝 마디 확정 | A6 챕터 전환, A7 상자 열림 | 홈에 "열린 상자 1개" |
| 부모 "줬어요" | "받았어요!" 축하, 상자 완료 표시 | 열린 상자가 사라진다 |

## 8. 시연 화면 순서

```
 1. 아이 폰 [A2]   양치하기 선택
        |
 2. 아이 폰 [A4]   영상 촬영, 캐릭터가 지켜봄
        |
 3. 아이 폰 [A5]   제출 축하, 캐릭터 한 칸 전진 (확인 대기)
        |
 4. 부모 폰 [P3]   "확인할 인증 1건"
        |
 5. 부모 폰 [P4]   영상 보고 승인
        |
 6. 아이 폰 [A1]   마디 확정, 챕터 끝 도달
        |
 7. 아이 폰 [A6]   챕터 전환, 배경이 바뀐다
        |
 8. 아이 폰 [A7]   상자 열림
        |
 9. 부모 폰 [P7]   "줬어요"
        |
10. 아이 폰        "받았어요!" 축하
```

- 선택: 4~5번에서 반려를 눌러 A8 "다시 해보자" 흐름을 보여준다.
- 시작 상태는 마디 9까지 승인된 데모용 데이터다. 한 건만 승인되면 챕터 1의 끝(10)에 닿는다. (가정)
