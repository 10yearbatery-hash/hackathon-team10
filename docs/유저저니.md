# 유저 저니

누가, 언제, 어떤 화면을 보는지를 그림으로 정리한다. 규칙과 용어는 `docs/서비스기획.md`가 기준이다. 화면 ID는 이 문서가 기준이다.

> 글꼴에 따라 한글 폭이 달라 테두리가 약간 어긋나 보일 수 있다.
> (가정)은 사용자가 말하지 않아 정리하면서 정한 것, (미정)은 아직 답을 받지 못한 것이다.

화면 ID: O = 온보딩(처음 한 번), C = 아이 영역, P = 부모 영역
폰은 1대이고, 아래 탭은 **홈 / 상점 / 부모** 세 개다.

## 1. 하루 저니

```
          아침            낮              저녁
        +--------+    +----------+    +------------+
 아이   | 오늘   | -> | 미션 하고| -> | 상점 구경  |
        | 단계   |    | 코인 받기|    | 선물 고르기|
        +--------+    +----------+    +------------+
 행동    홈에서        촬영하고        코인으로 사기
         단계 누름     제출
 감정    오늘도 가보자 뿌듯하다        갖고 싶다!
            |             |               |
 ...........|.............|...............|..........
            v             v               v
        +--------+    +--------+     +------------+
 부모   | 신경   |    | 신경   |     | 인증 확인  |
        | 안 씀  |    | 안 씀  |     | 선물 주기  |
        +--------+    +--------+     +------------+
 행동    잔소리 없음   잔소리 없음    PIN 입력, 한 건씩
                                      성공/실패, 줬어요
 감정    편하다        편하다         아이가 귀엽다
```

## 2. 처음 시작하는 흐름 (온보딩)

처음 한 번만 거친다. 이후에는 앱을 열면 홈이 바로 나온다.

```
[O1 시작] --"시작" 누름(소리 허용)--> [O2 온보딩 영상]
                                           |
                                           v
                                    [O3 하강 연출]  100단계에서 1단계로
                                           |
                                           v
                                    [O4 부모님께 폰 넘기기]
                                           |
        +----------------------------------+
        v
 [O5 PIN 만들기] -> [O6 아이 이름] -> [O7 미션 고르기]
                                           |
                                           v
                              [O8 첫 미션 같이 하기]  = C3 촬영 화면
                                           |
                                           v
                              [O9 1단계 클리어]  = C4 기쁨 + C5 코인
                                           |
                                           v
                              [C1 홈]  2단계에 서 있음
```

```
                |                        |

        v                     v                     v

     |                     |                      |
     v                     v                      v
   C2 단계 팝업          C10 구매 팝업          P2 부모 홈
     |                  (부족/성공)               |
     v                                  +--------+--------+--------+
   C3 촬영                              v        v        v        v
     |                                P3 인증  P4 선물  P5 미션  P6 선물

                                        |
                                        v
                                  (아이 화면에서) C8 다시 해보자
```

## 4. 인증 한 건이 지나가는 길

폰이 1대라서 서버와 기기 사이의 주고받음은 없다. 아이 영역과 부모 영역이 같은 폰 안의 같은 데이터를 본다.

```
 아이 영역                         폰 안의 저장소              부모 영역
 ---------                         -------------               ---------
 1. 단계 누르고 미션 선택
 2. 촬영 (캐릭터가 위에서 지켜봄)
 3. 제출 -----------------------> 4. 사진/영상 저장
                                     상태: 클리어
 5. 즉시 기쁨 연출
    +10코인, 한 단계 오름
                                                        6. (나중에) 부모 탭
                                                           PIN 입력
                                                        7. 인증을 한 건씩 봄
                                                  +---- 8a. 성공: 변화 없음
                                                  |     8b. 실패: 취소 처리
                                  9. 상태 변경 <--+
 10. 다음에 홈을 열면 반영
     8b: 캐릭터 한 단계 하강,
         -10코인, "다시 해보자"
```

- 5번은 부모 확인을 기다리지 않고 바로 보여준다. 아이가 기다리지 않는 것이 핵심이다.
- 부모가 확인하는 시점은 부모가 정한다. 기한은 없다.
- 아이가 폰을 쥐고 있을 때 실패가 반영되면 바로 C8이 나오고, 그렇지 않으면 다음에 홈을 열 때 나온다. (가정)

## 5. 촬영 화면 연출 (확정)

위쪽에 파란 펭귄이 두리번거리며 쳐다보는 **영상 칸**, 아래쪽에 **카메라 화면**이 있다. 영상은 `assets/character/hero/video/hero_look_idle.mp4`(4초, 소리는 음소거)를 반복한다.

영상은 1280×720의 상반신(머리~가슴) 영상이라 다리와 발은 나오지 않는다. 칸 위에 말풍선("화면은 잠깐 내려놓고 해봐!")을 따로 두어 얼굴을 가리지 않고, 영상은 머리 깃털부터 가슴까지 모두 보이게 한다.

```
+------------------+
|  ( 말풍선 )      |
|  [펭귄 영상]     |
|  두리번거리며    |
|  쳐다본다        |
+------------------+
|  카메라 화면     |
|                  |
+------------------+
```

- 영상의 반복 이음새가 튀는 문제(처음과 끝 프레임이 이어지지 않음)는 구현 때 처리한다.
- 영상 가로를 135%로 키워 가운데만 보이게 하면 오른쪽 아래의 작은 별 마크가 가려진다.

## 6. 화면별 레이아웃

### 온보딩

#### O1. 시작

```
+--------------------------------+
|                                |
|     (눈 덮인 마을 배경)        |
|                                |
|         [ 앱 로고 ]            |
|                                |
|    [ 파란 펭귄이 숨을 쉼 ]    |
|                                |
|      +------------------+      |
|      |     ▶  시작      |      |
|      +------------------+      |
+--------------------------------+
```

- 앱을 열면 먼저 스플래시가 나온다: 파란 화면에 펭귄이 쑥 올라와 고개를 갸웃하고, 화면이 동그랗게 오므라들며 시작 화면이 드러난다 (약 2.4초, 열 때마다).
- 시작 화면: 펭귄, "빙하루" 로고, 한 줄 소개가 차례로 튀어나오고 [시작하기] 버튼이 올라온다.
- [시작하기] → 펭귄이 통통 튀어 들어와 말풍선에 "안녕! 나는 파란 펭귄이야. / 공주를 구하러 같이 가 줄래?"가 한 글자씩 써진다. 다 써지면 [계속하기]가 켜지고 누르면 O2 영상으로 간다.
- "시작"을 눌러야 폰이 소리 재생을 허용한다. 그래서 영상 앞에 이 화면이 꼭 필요하다.
- 이미 온보딩을 끝낸 폰에서는 이 화면을 건너뛰고 홈으로 간다.

#### O2. 온보딩 영상

```
+--------------------------------+
|        (하늘색 빈 공간)        |
|  +--------------------------+  |
|  |  납치 영상 (세로, 꽉 차게)|  |
|  |  소리 있음, 10초         |  |
|  +--------------------------+  |
|        (하늘색 빈 공간)        |
+--------------------------------+
```

- 세로 화면 가운데에 넣는다. 위아래 빈 공간은 영상의 하늘색 계열로 채운다.
- 끝나면 자동으로 O3으로 넘어간다. 건너뛰기는 없다.
- 영상 내용: 두 펭귄이 하트를 날리며 논다 -> 보라색 포털에서 흰 여우가 나온다 -> 분홍 펭귄이 비눗방울에 갇혀 포털로 끌려간다 -> 포털 안에 성이 보인다 -> 파란 펭귄이 놀라 소리친다.

#### O3. 하강 연출


- 100단계 이미지를 코드로 위에서 아래로 움직여 만든다. 이미지는 세로로 긴 한 장으로 받는다. (가정)
- 끝에 한 줄 대사가 나온다. (가정, 음성은 나중)

```
|      [ 파란 펭귄이 안내 ]     |

```

```
|  +--------------------------+  |
|  | [손] 손씻기      영상 찍기|  |
```

#### O8. 첫 미션 같이 하기

- 위에 "엄마 아빠랑 같이 해봐요!"가 한 줄 붙는다.
- 이후는 C3 촬영 화면과 같다.

#### O9. 1단계 클리어

- C4 기쁨 연출, C5 +10코인이 나온다.
- 첫 미션은 **연습**이다(ADR-014). 단계를 올리지 않고, 홈에서 1일 발판에 선 채로 "이제부터는 혼자서!"가 나온다.
- 아이는 바로 1일 미션을 혼자 해서 2단계로 올라갈 수 있다.
- 이 첫 미션은 부모의 "확인할 인증"에 쌓인다. (가정, 시연에서 성공·실패 장면을 보이기 위해)

### 아이 영역

원칙: 글씨 최소화, 그림과 큰 버튼 중심. 터치 영역은 크게 한다.

#### C1. 홈 (길)

> 피그마 v3(ADR-013)로 바뀌었다: 10개 장의 그림 지도를 위에서 아래로 잇고, 1일이 맨 위, 100일(마법성)이 맨 아래다. 단계를 누르면 아래에서 올라오는 목록 대신 가운데에 DAY 미션 카드가 뜬다. 아래 그림은 처음 기획이다.

아래에서 위로 올라가는 세로 S자 길이다. 위쪽에 번호가 큰 단계가 있다.

```
+--------------------------------+
| 빙하루                  (c) 300 |
+--------------------------------+
| 1장  눈꽃 마을                 |
| 공주님 성까지 77칸 남았어요!   |
|                       ( 15 )   |
|                  (잠김)        |
|             ( 14 )             |
|            (잠김)              |
|   [파란 펭귄]                  |
|     ( 13 )  <- 지금            |
|        ( 12 )                  |
|     ( 11 )                     |
|            ( 10 )              |
|        ...  (아래로 스크롤)    |
+--------------------------------+
| [선물] 다음 선물까지 코인 N    |
+--------------------------------+
|  [홈]     [상점]     [부모]    |
+--------------------------------+
```

- 위쪽 헤더: 앱 이름(임시), 코인 칩, 장 이름, 성까지 남은 칸 수
- 단계는 네 가지 모양이다: 완료(파랑), 지금(캐릭터가 서 있음, 강조), 잠김(회색), 내일 만나자(오늘 다 깬 단계 위, 달 모양 표시). (가정)
- 캐릭터는 가만히 있지 않고 숨 쉬는 듯 움직인다.
- 맨 아래 "다음 선물까지" 카드는 가장 싼 선물에 필요한 코인을 보여준다. (가정, 보내주신 이미지 참고)

#### C2. 단계 팝업 (그날의 미션 목록)

단계를 누르면 아래에서 올라온다.

```
+--------------------------------+
|   (길 화면이 어둡게 보임)      |
+================================+
|  13단계  오늘의 미션           |
|  +--------------------------+  |
|  | [칫솔] 양치하기   영상   |  |
|  |       [ 하러 가기 ]      |  |
|  +--------------------------+  |
|  | [손] 손씻기    완료 (v)  |  |
|  +--------------------------+  |
|  | [책] 책읽기  다시 해보자 |  |
|  |       [ 하러 가기 ]      |  |
|  +--------------------------+  |
|  오늘 1 / 3 완료               |
+--------------------------------+
```

- 지금 단계의 팝업만 미션을 하러 갈 수 있다. 잠긴 단계를 누르면 "아직 열리지 않았어!" 하고 단계가 흔들린다.
- 미션이 1개면 팝업 없이 바로 촬영 화면으로 가도 된다. (미정)
- 미션 카드는 세 가지 상태다: 아직(버튼), 완료(체크), 다시 해보자(실패 후, 버튼).
- 아이에게는 "부모 확인 대기"를 따로 보여주지 않는다. 제출하면 완료다. (가정)

#### C3. 미션 촬영

영상 미션:

```
+--------------------------------+
| <  양치하기              00:12 |
+--------------------------------+
|  +--------------------------+  |
|  |   [ 파란 펭귄 영상 ]     |  |
|  |   두리번거리며 쳐다봄    |  |
|  +--------------------------+  |
|  +--------------------------+  |
|  |                          |  |
|  |       카메라 화면        |  |
|  |       ● 녹화 중          |  |
|  +--------------------------+  |
|     [########-------]          |
|        남은 시간               |
|     (  ● 시작  )               |
|     (  ✔ 제출  )  <- 비활성    |
+--------------------------------+
```

- 부모가 정한 길이(5~30초)가 지나면 녹화가 자동으로 끝나고 제출 버튼이 켜진다. (가정)
- 사진 미션은 시작 버튼이 [ ● 찍기 ]가 되고, 찍으면 미리보기와 [다시 찍기] [제출]이 나온다.
- 제출 버튼이 꺼져 있는 동안은 누를 수 없다. 인증 없이 넘어가는 방법은 없다.
- 뒤로 가기를 누르면 촬영한 내용은 버려진다.

#### C4. 클리어 기쁨 - 즉시 연출

```
+--------------------------------+
|                                |
|      *    반짝  반짝    *      |
|                                |
|          +----------+          |
|          |[파란 펭귄|          |
|          |  환호]   |          |
|          +----------+          |
|                                |
|            잘했어!             |
|                                |
|      효과음이 나온다          |
+--------------------------------+
```

- 부모 확인을 기다리지 않고 바로 나온다. 몇 초 뒤 C5로 넘어간다.

#### C5. 코인 획득

```
+--------------------------------+
|                    (c) 300     |
|                                |
|        +10                     |
|     (c)(c)(c)(c)(c)           |
|     코인이 위로 날아가         |
|     오른쪽 위 코인 칩에        |
|     쏙 들어간다               |
|                                |
|      +------------------+      |
|      |       확인       |      |
|      +------------------+      |
+--------------------------------+
```

- 코인이 날아가 칩에 들어가면서 숫자가 올라가는 것을 보여준다. 효과음이 같이 나온다.

#### C6. 단계 오르기

- 오늘 단계의 미션을 **전부** 깼다면, 홈에서 캐릭터가 다음 단계로 걸어 올라간다.
- 아직 깰 미션이 남았다면 C2 목록으로 돌아온다.
- 오늘 할 일이 끝났으면 "내일 만나자" 상태가 되고, 캐릭터가 쉬는 모습이다.
- 한 장(10단계)을 끝내는 단계라면 C7이 나온다.

#### C7. 장 전환 (나중)

배경과 색이 크게 바뀌는 연출이다. 시연은 1단계만이라 이번에는 만들지 않는다. 10장의 이름이 정해지면 만든다. (미정)

#### C8. 다시 해보자 - 실패 안내

```
+--------------------------------+
|                                |
|          +----------+          |
|          |[파란 펭귄|          |
|          |  응원]   |          |
|          +----------+          |
|                                |
|          다시 해보자!          |
|     한 번 더 찍어볼까?         |
|                                |
|   ( 2단계 ) -> ( 1단계 )       |
| 퀘스트를 올바르게 하지 않았어! |
|        코인 -10                |
|                                |
|   +--------+  +--------+       |
|   | 다시   |  | 나중에 |       |
|   | 찍기   |  |        |       |
|   +--------+  +--------+       |
+--------------------------------+
```

- 벌을 받은 느낌이 나지 않게 캐릭터는 슬퍼하지 않고 응원하는 표정을 쓴다. (가정)
- [다시 찍기]는 실패한 미션의 촬영 화면(C3)으로 간다. [나중에]는 홈으로 간다. 홈의 단계 팝업에는 "다시 해보자"로 남는다.

#### C9. 상점

피그마 "상점 01~04". 나무 간판(눈꽃 선물 상점), 줄무늬 차양, 양쪽 기둥, 아래 나무 마루가 있는 가게다. 아래 탭 대신 "‹ 모험으로"로 홈에 돌아간다. 피그마의 "크레딧"은 앱 용어에 맞춰 "코인"으로 쓴다.

```
 01 어서 와!                 02 상품 둘러보기
+--------------------------+ +--------------------------+
|    [ 눈꽃 선물 상점 ]    | |    [ 눈꽃 선물 상점 ]    |
| ‹ 모험으로   (● 120 코인)| | ‹ 모험으로   (● 120 코인)|
| ~~~~~~ 줄무늬 차양 ~~~~~~| | ~~~~~~ 줄무늬 차양 ~~~~~~|
| | (안녕~ 뭐 사러 왔어?) || | | +------------------+ | |
| |     [펭귄 점원]      || | | | 가족 영화 보기   | | |
| | [== PENGUIN SHOP ==] || | | | 한 줄 설명       | | |
| | 매일 모은 코인으로   || | | | 50 코인 · 구매하기| | |
| | 가족과 특별한 시간을 || | | +------------------+ | |
| | [  상품 구경하기  ]  || | |   ... 선물 네 개     | |
| [====== 나무 마루 ======]| | [====== 나무 마루 ======]|
+--------------------------+ +--------------------------+
```

- 선물은 네 개이고 이름과 가격은 부모가 바꿀 수 있다 (P6). 기본 선물에는 한 줄 설명이 붙고, 부모가 만든 선물은 공통 문구가 붙는다.
- 코인이 모자란 선물은 연하게 보이고, 가격 옆에 "N개 더 모으자"가 붙는다. 누르면 C10의 부족 화면이 나온다.

#### C10. 구매

```
 구매 확인(팝업)         03 구매 완료              04 코인 부족
+------------------+   +--------------------+   +--------------------+
|  이 선물을 살까? |   | (구매해 줘서       |   | (미안… 코인이      |
|  가족 영화 보기  |   |   고마워!)         |   |   부족해ㅜ)        |
|  (c) 50          |   |   [윙크 펭귄]      |   |   [우는 펭귄]      |
|  [살래요]        |   | [PENGUIN SHOP]     |   | [PENGUIN SHOP]     |
|  [취소]          |   | 가족 영화 보기     |   | N코인만 더 모으고  |
+------------------+   | [다른 선물도 볼래] |   | [모험하러 가기]    |
                       +--------------------+   |  다른 상품 보기    |
                                                +--------------------+
```

- [살래요]를 누르면 코인이 **바로** 빠지고 03 구매 완료가 나온다. 확인 팝업은 아이가 실수로 사지 않게 남겨 둔다.
- 코인이 가격보다 적으면 확인 팝업 대신 04 코인 부족이 나온다. 펭귄이 울지만 "다시 만나!"로 응원한다.
- "모험하러 가기"는 홈으로, "다른 상품 보기"와 "다른 선물도 볼래"는 02 상품 목록으로 간다.
- 시연에서는 이 부족 화면만 보여준다.

### 부모 영역

원칙: 빠른 확인과 처리, 처리할 일이 맨 위. 아이 영역과 색이나 분위기를 다르게 해서 "지금 부모 화면"이라는 것이 한눈에 보이게 한다. (가정)

#### P1. PIN 입력

```
+--------------------------------+
| <  부모님 확인                 |
+--------------------------------+
|                                |
|      비밀번호를 입력하세요     |
|                                |
|          (o) (o) ( ) ( )       |
|                                |
|        [1]   [2]   [3]         |
|        [4]   [5]   [6]         |
|        [7]   [8]   [9]         |
|              [0]   [<]         |
+--------------------------------+
```

- 틀리면 칸이 흔들리고 다시 입력한다. 횟수 제한은 두지 않는다. (가정)
- PIN을 잊어버렸을 때의 복구는 이번 범위에 없다.

#### P2. 부모 홈

```
+--------------------------------+
| 하늘이 부모님     [아이 화면으로] |
+--------------------------------+
| +----------------------------+ |
| | [!] 확인할 인증 2건        | |
| | 양치하기, 비타민 먹기      | |
| |                [확인하기]  | |
| +----------------------------+ |
| +----------------------------+ |
| | [선물] 구매한 선물 1개     | |
| | 가족 영화 보기             | |
| |                [확인하기]  | |
| +----------------------------+ |
|                                |
| +----------+ +----------+      |
| | 미션     | | 선물     |      |
| | 관리     | | 관리     |      |
| +----------+ +----------+      |
| +--------------------------+   |
| | 구독 안내                |   |
| +--------------------------+   |
+--------------------------------+
|  [홈]     [상점]     [부모]    |
+--------------------------------+
```

- 처리할 일이 위에 있다. 없을 때는 "확인할 인증이 없어요"를 보여준다.
- [아이 화면으로]를 누르면 PIN 없이 홈으로 돌아간다. 부모 탭에 다시 들어올 때는 PIN을 또 입력한다. (가정)

#### P3. 인증 확인 - 한 건씩

```
+--------------------------------+
| <  인증 확인               1/2 |
+--------------------------------+
|  양치하기          오늘 08:10  |
|                                |
|  +--------------------------+  |
|  |                          |  |
|  |      [ 영상 재생 ]       |  |
|  |         ▶  0:18          |  |
|  |                          |  |
|  +--------------------------+  |
|                                |
|  +------------+ +------------+ |
|  |    실패    | |    성공    | |
|  +------------+ +------------+ |
|   실패하면 캐릭터가 한 단계    |
|   내려가고 코인 10이 빠져요    |
+--------------------------------+
```

- 사진 미션은 영상 자리에 사진이 들어간다.
- 성공이나 실패를 누르면 다음 건으로 넘어간다. 마지막 건을 처리하면 부모 홈으로 돌아간다. (가정)
- [실패]를 누르면 "정말 실패로 할까요?" 확인 팝업이 한 번 나온다. (가정, 실수 방지)

#### P4. 구매한 선물 확인

```
+--------------------------------+
| <  구매한 선물                 |
+--------------------------------+
| +----------------------------+ |
| | [영화] 가족 영화 보기      | |
| | 하늘이가 오늘 샀어요       | |
| |                [줬어요]    | |
| +----------------------------+ |
| 줬어요를 누르면 목록에서       |
| 사라져요                       |
+--------------------------------+
```

#### P5. 미션 관리

```
+--------------------------------+
| <  미션 관리                   |
+--------------------------------+
| +----------------------------+ |
| | [칫솔] 양치하기      영상  | |
| |  영상 길이  [ 15 ] 초      | |
| |  [미션 바꾸기]             | |
| +----------------------------+ |
| +----------------------------+ |
| | [자물쇠] 미션 더 추가하기  | |
| |  구독하면 할 수 있어요     | |
| +----------------------------+ |
|                                |
|  +--------------------------+  |
|  |          저장            |  |
|  +--------------------------+  |
+--------------------------------+
```

- 무료는 미션 1개라서 "수정"은 영상 길이 바꾸기와 다른 미션으로 바꾸기다. 마지막 1개는 삭제할 수 없고 바꾸기만 된다. (가정)
- 구독하면 미션이 목록으로 늘고, 각 줄에 [삭제]가 생긴다.
- 미션을 바꾸면 오늘 이미 한 인증은 그대로 두고 다음 단계부터 적용한다. (가정)
- 부모가 새 미션을 직접 쓰는 기능은 이번에 없다. 발표에서 말로 설명한다.

#### P6. 선물 관리

```
+--------------------------------+
| <  선물 관리                   |
+--------------------------------+
| +----------------------------+ |
| | [영화] 이름 [가족 영화 보기]| |
| |        가격 [ 50 ] 코인    | |
| +----------------------------+ |
| | [식탁] 이름 [저녁 메뉴 고르기]|
| |        가격 [ 100 ] 코인   | |
| +----------------------------+ |
| | [퍼즐] 이름 [특별 놀이 20분]|
| |        가격 [ 150 ] 코인   | |
| +----------------------------+ |
| | [나무] 이름 [주말 공원 고르기]|
| |        가격 [ 200 ] 코인   | |
| +----------------------------+ |
|  +--------------------------+  |
|  |          저장            |  |
|  +--------------------------+  |
+--------------------------------+
```

- 선물은 4개로 고정이고 이름과 가격만 바꿀 수 있다. 가격은 10 이상의 정수다. (가정)

#### P7. 구독 안내 (가짜 결제)

```
+--------------------------------+
| <  구독 안내                   |
+--------------------------------+
|      [ 파란 펭귄 + 별 ]        |
|                                |
|   더 많은 모험을 떠나요!       |
|                                |
|   (v) 미션 더 추가하기         |
|   (v) 21단계 이후 계속 가기    |
|                                |
|   월 9,900원                   |
|                                |
|  +--------------------------+  |
|  |       구독하기           |  |
|  +--------------------------+  |
|    (이번 버전은 시연용 화면)   |
+--------------------------------+
```

- [구독하기]를 누르면 실제 결제 없이 "구독이 시작됐어요" 화면이 나오고 구독 상태가 켜진다. (가정)
- 이 화면은 O7의 자물쇠 줄, P5의 "미션 더 추가하기", 20단계 이후 진행을 막을 때 나온다.
- 20단계 이후 막는 동작은 시연이 1단계만이라 이번에 만들지 않는다.

## 7. 상태별 화면 변화

한 건의 인증이 지나가는 동안 두 영역이 어떻게 달라지는지 정리한다.

| 시점 | 아이 영역 (홈) | 부모 영역 |
|---|---|---|
| 인증 전 | 캐릭터가 지금 단계에 서 있다 | 변화 없음 |
| 제출 직후 | 기쁨 연출, +10코인, 미션 카드가 완료. 단계의 미션을 다 깼으면 캐릭터가 올라감 | "확인할 인증 +1" |
| 부모 성공 | 변화 없음 | 그 건이 목록에서 사라진다 |
| 부모 실패 | 캐릭터가 한 단계 내려오고 C8, 코인 -10. 미션 카드가 "다시 해보자" | 그 건이 목록에서 사라진다 |
| 오늘 단계 모두 클리어 | "내일 만나자" | 변화 없음 |
| 선물 구매 | 코인이 바로 빠지고 "주문했어요" | "구매한 선물 +1" |
| 부모 "줬어요" | 변화 없음 | 그 건이 목록에서 사라진다 |

## 8. 시연 화면 순서

```
 1. [O1]  시작 버튼
        |
 2. [O2]  온보딩 영상
        |
 3. [O3]  하강 연출
        |
 4. [O4~O7] 부모 PIN, 아이 이름, 미션 고르기
        |
 5. [O8]  첫 미션 촬영, 캐릭터가 지켜봄
        |
 6. [O9]  연습 클리어, +10코인, 1일 발판 → 1일 미션을 혼자 해서 2단계로
        |
 7. [C9]  상점, "미안… 코인이 부족해ㅜ"
        |
 8. [P1~P3] 부모 탭, 인증 확인, 실패 -> [C8] 한 단계 내려옴
        |
 9. [P5, P7] 미션 관리, 구독 안내
        |
10. 말로 설명: 20단계 이후 유료, 10장 100단계 (직접 만드는 미션은 P5에서 보여줄 수 있다)
```

- 시연은 1단계만 보여준다. 장 전환(C7)과 20단계 결제 잠금은 만들지 않는다.
- 8번은 온보딩 첫 미션이 확인 대기에 쌓인다는 가정에 기댄다.
