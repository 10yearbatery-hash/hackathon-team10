펭귄 모험 화면 레이아웃

앱 이름은 임시입니다. 이미지 없이 박스와 글자만으로 그린 화면 뼈대입니다. 어떤 페이지가 필요한지, 각 화면에 무엇이 들어가는지 확인하려고 만들었습니다. 색, 그림, 캐릭터 모양은 디자인에서 정합니다. 기준 문서는 docs/유저저니.md입니다.

한눈에 보기 온보딩 O1~O9 아이 영역 C1~C10 (홈 포함) 부모 영역 P1~P7

앱 구조

폰은 1대이고, 아이와 부모가 나눠 씁니다. 아래 탭은 홈 / 상점 / 부모 세 개이고, 부모 탭은 비밀번호(PIN)를 입력해야 들어갑니다. 처음 한 번은 온보딩을 거칩니다. 화면은 모두 26개이고 시연에 필요한 것이 25개, 나중에 만들 것이 1개(C7)입니다.

처음 한 번 O1→O2→O3→O4→O5→O6→O7→O8→O9→C1 홈
매일 (미션) C1 홈→C2 미션 목록→C3 촬영→C4 기쁨→C5 코인→C6 단계 오름→C1 홈
상점 C1 홈→ 상점 탭 →C9 상점→C10 구매 팝업
부모 부모 탭→P1 PIN→P2 부모 홈→P3 인증 확인/P4 선물 확인/P5 미션 관리/P6 선물 관리/P7 구독 안내
실패하면 P3에서 실패→ 아이가 다음에 홈을 열면 →C8 다시 해보자

보는 법

O 온보딩 C 아이 영역 P 부모 영역 필수 시연에 나옴 나중 이번에 안 만듦 (점선 틀) 점선 회색 박스 = 그림, 영상, 사진이 들어갈 자리

O 온보딩 (처음 한 번만)

영상을 보고, 부모가 비밀번호와 이름과 미션을 정하고, 아이와 첫 미션을 해서 1단계를 클리어합니다. 끝나면 2단계부터 본 게임입니다.

C 아이 영역 (홈 / 상점)

글씨는 최소로, 그림과 큰 버튼 중심입니다. 인증하면 바로 클리어되고 코인을 받습니다.

P 부모 영역 (PIN으로 들어감)

처리할 일이 맨 위에 있고, 한 건씩 빠르게 넘깁니다. 아이 화면과 분위기를 다르게 해서 “지금은 부모 화면”임이 보여야 합니다.
