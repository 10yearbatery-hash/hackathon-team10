# PRD: 빙하루

- 상태: 초안
- 원본 기획: `docs/서비스기획.md` (규칙과 용어), `docs/유저저니.md` (화면 레이아웃은 6장이 기준)
- 이 문서가 기획서와 다르면 이 문서를 따른다. 바꿀 때는 `docs/adr.md`에 이유를 남긴다.
- 표기: **(가정)** = 사용자가 말하지 않아 정리하면서 정한 것, **(미정)** = 답을 아직 받지 못한 것

## 1. 한 줄 요약

5~8세 아이가 생활습관 미션을 사진·영상으로 인증하면 파란 펭귄이 100단계 길을 올라가며 공주를 구하러 가고, 모은 코인으로 부모가 약속한 선물을 고르는 습관 미션 게임. 폰 1대를 아이와 부모가 나눠 쓴다.

## 2. 문제

- 부모는 아이의 생활습관(손씻기, 양치 등)을 잔소리 없이 이어가게 하고 싶다.
- 어릴 적 칭찬 스티커는 아이가 금방 흥미를 잃고, 부모도 붙이고 관리하기 번거롭다.
- 5~8세 아이는 글을 잘 못 읽고 혼자 폰을 쓰는 시간이 짧아서, 조작이 복잡하면 쓰지 않는다. 대개 엄마 폰을 빌려서 쓴다.

## 3. 대상 사용자

| 사용자 | 특징 | 앱에서 원하는 것 |
|---|---|---|
| 아이 (5~8세) | 글을 읽기 어려운 아이도 있다. 엄마 폰을 빌려서 쓴다. | 하면 바로 칭찬받기, 캐릭터가 움직이는 재미, 갖고 싶은 선물 |
| 부모 | 바쁘다. 잔소리를 줄이고 싶다. 아이가 진짜 했는지는 확인하고 싶다. | 한 건씩 빠르게 확인, 선물을 정해서 약속 지키기 |

## 4. 목표와 성공 기준

- 1차: 웹앱(PWA)의 완벽한 구현과 시연. 시연이 가장 중요하다.
- 2차: 1차에 도달하면 Expo Go 형태의 앱 전환을 검토한다.
- 수익 목표: 월 구독(미션 추가, 20단계 이후). 이번 시연은 결제 화면까지만 만든다.
- 성공 기준 (이번 시연)
  - 폰 1대로 온보딩부터 1단계 클리어까지 끊김 없이 보여줄 수 있다.
  - 부모 영역에서 인증을 확인하고 실패를 눌러 캐릭터가 내려오는 것을 보여줄 수 있다.
  - 상점에서 "미안… 코인이 부족해ㅜ"가 나오고, 미션 관리와 구독 안내 화면을 보여줄 수 있다.
  - 캐릭터의 움직임과 클리어 연출이 "듀오링고급"이라고 느껴질 만큼 생동감 있다. (정량 기준은 미정)

## 5. 범위

| 구분 | MVP에 포함 | 이번에 하지 않음 |
|---|---|---|
| 온보딩 | 시작, 영상, 하강 연출, PIN·이름·미션 설정, 첫 미션과 1단계 클리어 | |
| 아이 | 길 홈, 단계 팝업, 사진·영상 촬영과 캐릭터 반응, 클리어와 코인 연출, 하강 안내, 상점과 구매 | 장 전환 연출, 20단계 이후, 음성 안내, 캐릭터 꾸미기 |
| 부모 | PIN, 홈, 인증 확인(건별), 구매한 선물 확인, 미션 관리, 선물 관리, 구독 안내(가짜 결제) | 직접 쓰는 미션, 리포트, 아이 여러 명, PIN 복구, 푸시 알림 |
| 기술 | 폰 안에 저장, PWA, 선택 로그인과 서버 저장(ADR-017) | 실제 결제, 소셜 로그인, 비밀번호 찾기 |

## 6. 핵심 루프와 시연 시나리오

```
미션 인증 -> 즉시 클리어 -> +10코인, 단계 오름 -> 코인 모으기 -> 상점에서 선물 고르기 -> 부모가 선물 주기
                   (부모는 원할 때 확인해서 성공/실패. 실패하면 한 단계 내려가고 -10코인)
```

시연 시나리오는 `docs/서비스기획.md` 15장과 `docs/유저저니.md` 8장에 있다. 요약: 시작 -> 영상 -> 하강 -> 부모 설정 -> 첫 미션 -> 1단계 클리어 -> 상점(코인 부족) -> 부모 확인에서 실패 -> 미션 관리와 구독 안내를 보여주고 나머지는 말로 설명한다.

## 7. 기능 요구사항

화면 ID는 `docs/유저저니.md`와 같다. 검증 가능한 수용 기준은 `plan/acceptance.json`에 있다.
우선순위: **필수** = 시연에 나오는 것, **나중** = 이번 시연에 안 나오는 것

### 공통

- **F-01 소리 허용 시작**: 처음 실행하면 "시작" 버튼이 있는 화면이 나오고, 누른 뒤부터 소리가 재생된다. (O1, 필수)
- **F-02 탭 이동**: 아래 탭 홈 / 상점 / 부모로 이동한다. 부모 탭은 PIN을 통과해야 한다. (필수)
- **F-03 효과음**: 클리어, 코인 획득, 버튼, 단계 오르기에 효과음이 있다. (필수)
- **F-04 로컬 저장**: 단계 진행, 코인, 인증 사진·영상, 선물, 설정을 폰 안에 저장한다. 앱을 껐다 켜도 유지된다. (필수, 가정)

### 온보딩

- **F-10 온보딩 영상**: 납치 영상(10초, 소리 포함)을 세로 화면 가운데에 재생한다. 건너뛰기는 없다. (O2, 필수)
- **F-11 하강 연출**: 100단계에서 1단계까지 카메라가 내려오고 한 줄 대사가 나온다. (O3, 필수)
- **F-12 부모 설정**: PIN 4자리(두 번 입력), 아이 이름, 기본 미션 5개 중 1개 선택(영상 미션은 길이 5~30초). (O4~O7, 필수)
- **F-13 첫 미션 체험**: 부모와 아이가 같이 첫 미션을 **연습으로** 촬영하고 클리어 연출과 +10코인을 받는다. 연습은 단계를 올리지 않아서 홈에서는 1일 발판에 그대로 서 있고 바로 1일 미션을 할 수 있다(ADR-014). 이 인증은 부모 확인 목록에 쌓인다. (O8~O9, 필수, 가정)

### 아이

- **F-20 길 홈**: 10개 장의 그림 지도를 위에서 아래로 이은 1~100단계 길(1일이 맨 위, ADR-013), 지금 단계에 서 있는 캐릭터, 코인 칩, 장 이름, 성까지 남은 칸 수, 다음 선물까지 필요한 코인을 보여준다. 단계는 완료 / 지금 / 잠김 / 내일 만나자 네 가지 모양이다. (C1, 필수)
- **F-21 단계 팝업**: 지금 단계를 누르면 그날의 미션 목록이 올라온다. 미션 카드는 아직 / 완료 / 다시 해보자 세 가지다. 잠긴 단계는 눌러도 열리지 않는다. (C2, 필수)
- **F-22 미션 촬영**: 위쪽에 펭귄 영상, 아래쪽에 카메라가 있다. 사진 미션은 찍기와 다시 찍기, 영상 미션은 남은 시간 막대와 자동 종료가 있다. 인증을 마쳐야 제출 버튼이 켜진다. (C3, 필수)
- **F-23 클리어와 코인**: 제출하면 즉시 캐릭터 환호 연출과 +10코인 획득 연출이 나온다. (C4, C5, 필수)
- **F-24 단계 오르기**: 오늘 단계의 미션을 전부 깨면 캐릭터가 다음 단계로 올라가고 "내일 만나자" 상태가 된다. (C6, 필수)
- **F-25 실패 안내**: 부모가 실패를 눌렀다면 캐릭터가 한 단계 내려오고 코인이 10 빠지며 "다시 해보자"가 나온다. (C8, 필수)
- **F-26 상점**: 선물 4개와 가격, 보유 코인을 보여준다. 코인이 모자란 선물은 연하게 보인다. (C9, 필수)
- **F-27 선물 구매**: 구매하면 코인이 바로 빠지고 부모 확인 목록에 쌓인다. 코인이 모자라면 펭귄 점원이 "미안… 코인이 부족해ㅜ"라고 말한다. (C10, 필수)
- **F-28 장 전환**: 10단계마다 배경과 색이 바뀐다. (C7, 나중)

### 부모

- **F-30 PIN 진입**: 부모 탭을 누르면 PIN 4자리를 입력해야 들어간다. 틀리면 흔들리고 다시 입력한다. (P1, 필수)
- **F-31 부모 홈**: 확인할 인증 건수, 구매한 선물 건수, 메뉴, 아이 화면으로 돌아가기 버튼을 보여준다. (P2, 필수)
- **F-32 인증 확인**: 인증을 한 건씩 보고 성공 또는 실패를 누른다. 실패는 확인 팝업을 한 번 거친다. (P3, 필수)
- **F-33 선물 확인**: 아이가 산 선물 목록에서 "줬어요"를 누르면 목록에서 사라진다. (P4, 필수)
- **F-34 미션 관리**: 현재 미션의 영상 길이를 바꾸고 다른 미션으로 바꾼다. 마지막 1개는 삭제할 수 없다. 구독 상태에서는 미션이 여러 개이고 삭제할 수 있다. (P5, 필수)
- **F-35 선물 관리**: 선물 4개의 이름과 가격을 수정한다. (P6, 필수)
- **F-36 구독 안내**: 구독 혜택과 가격(월 9,900원) 안내, 가짜 결제 화면, 결제 후 구독 상태 켜기. (P7, 필수)
- **F-37 20단계 잠금**: 구독하지 않은 상태로 20단계를 넘으려 하면 구독 안내가 나온다. (나중)

## 8. 규칙

- **R-01 하루 한 단계**: 하루에 한 단계씩 진행한다. 기준은 기기의 현지 자정이다. 오늘 단계를 다 깨면 "내일 만나자"가 되고 다음 단계는 자정에 열린다. 못 한 날은 그 단계에 그대로 남는다. (가정)
- **R-02 전부 깨야 오른다**: 한 단계 안의 미션을 전부 클리어해야 다음 단계로 올라간다. 앞으로 갈 단계는 잠겨 있다.
- **R-03 길 구조**: 1~100단계이고 10단계마다 1장이 끝난다 (모두 10장). 장 이름은 사용자가 정한다. (미정)
- **R-04 인증 필수**: 인증 없이 "했어요"만 누르는 방식은 없다. 영상 미션은 부모가 정한 길이(5~30초)를 끝까지 찍어야 제출 버튼이 켜진다. (가정) 영상은 화질이 낮아도 된다.
- **R-05 즉시 클리어**: 인증을 제출하면 부모 확인 전에도 클리어로 친다.
- **R-06 코인 획득**: 미션 1건을 클리어하면 10코인을 받는다.
- **R-07 부모 확인**: 부모는 반드시 확인한다는 전제이며 기한은 없다. 성공은 변화가 없다. 실패는 R-08을 따른다.
- **R-08 실패 처리**: 캐릭터가 한 단계 내려가고 코인 10을 회수한다. 실패한 미션은 지금 단계의 목록에 "다시 해보자"로 올라오고, 다시 성공하면 10코인을 다시 받는다. (가정)
- **R-09 마이너스 허용**: 이미 쓴 코인이 회수되어도 코인은 마이너스가 될 수 있다.
- **R-10 구매 조건**: 보유 코인이 가격 이상일 때만 구매할 수 있다. 구매하면 코인이 즉시 빠진다. 모자라면 "미안… 코인이 부족해ㅜ"가 나온다.
- **R-11 선물 전달**: 구매한 선물은 부모 목록에 쌓이고, 부모가 "줬어요"를 누르면 완료된다. 구매한 선물은 취소할 수 없다. (가정)
- **R-12 기본 선물**: 4개이고 가격은 50, 100, 150, 200이다. 이름과 가격은 부모가 수정할 수 있다. 가격은 10 이상의 정수다. (이름과 입력 범위는 가정)
- **R-13 기본 미션**: 손씻기(영상), 양치하기(영상), 비타민 먹기(사진), 책읽기(사진), 준비물 챙기기(사진) 5개다. 부모가 새 미션을 직접 쓰는 기능은 이번에 없다.
- **R-14 무료와 유료**: 무료는 미션 1개, 1~20단계다. 미션 추가와 20단계 이후는 월 구독이다. 실제 결제는 붙이지 않는다.
- **R-15 내역 없음**: 코인이 들어오고 나간 내역을 보는 화면은 만들지 않는다.
- **R-16 아이 1명**: 지금은 아이가 한 명이다.
- **R-17 PIN**: 4자리다. 복구 기능은 없다.

## 9. 시드 데이터

- 시연 시작 상태: **앱을 처음 여는 빈 상태**다. 온보딩부터 시작한다.
- 시작 코인: 0
- 시작 단계: 1단계. 온보딩에서 첫 미션을 클리어하면 2단계에 선다.
- 기본 선물 4개 (이름은 가정)

| 이름 | 가격 |
|---|---|
| 가족 영화 보기 | 50 |
| 저녁 메뉴 고르기 | 100 |
| 특별 놀이 20분 | 150 |
| 주말 공원 고르기 | 200 |

- 기본 미션 5개: R-13 참고
- 빈 상태
  - 확인할 인증이 없을 때: 부모 홈에 "확인할 인증이 없어요"
  - 구매한 선물이 없을 때: "구매한 선물이 없어요"
- 시연 직전에 앱을 처음 상태로 되돌릴 수 있는 방법이 필요하다. (미정, 구현 때 정한다)

## 10. UX와 디자인 원칙

### 공통

- 듀오링고급의 완성도를 목표로 한다. 움직임, 효과음, 연출이 모두 중요하다.
- 폰 세로 화면 하나만 기준으로 한다.
- 아래 탭은 홈 / 상점 / 부모 세 개다.
- 캐릭터는 성장하지 않는다. 바뀌는 것은 배경과 색이다.

### 사용자 유형별

- 아이
  - 글씨는 최소로 하고 그림과 큰 버튼 중심으로 만든다. (5~8세, 읽기 어려운 아이가 있음)
  - 터치 영역은 크게 잡는다. 한 손가락으로 쉽게 누를 수 있어야 한다.
  - 인증하자마자 바로 칭찬한다. 기다리게 하지 않는다.
  - 실패 안내는 벌처럼 느껴지지 않게 응원하는 표정과 "다시 해보자"를 쓴다.
- 부모
  - 처리할 일이 맨 위에 있다. 한 건씩 빠르게 넘긴다.
  - 부모 영역은 아이 영역과 분위기를 다르게 해서 "지금 부모 화면"임이 보이게 한다. (가정)

### 피할 것

- 아이가 부모 확인을 기다리게 만드는 흐름
- 인증 없이 넘어갈 수 있는 길
- 아이 화면에 긴 문장이나 어려운 단어
- 실패나 하강을 벌처럼 보이게 하는 연출
- 이전 두 기기 구조의 흔적(가족 코드, 기기 역할 선택, 보물상자, 챕터 보상)

## 11. 비기능 요구사항

- **N-01 폰 세로 화면**: 폰 세로 화면(좁은 폭)을 기준으로 만든다. 가로나 데스크톱은 맞추지 않는다.
- **N-02 영상 용량**: 촬영 영상은 화질을 낮춰 저장한다. 폰 저장 용량의 한계를 구현 전에 시험한다. (미정)
- **N-03 카메라**: 카메라와 마이크 권한 요청이 나오고 거절했을 때의 안내가 있어야 한다. 아이폰 Safari와 안드로이드 Chrome 실기기에서 카메라와 영상 재생을 확인한다. (아직 검증하지 못함)
- **N-04 소리**: 폰 브라우저는 사용자가 터치하기 전에는 소리를 막는다. 첫 터치(O1) 이후에만 소리가 나온다.
- **N-05 움직임**: 캐릭터와 연출은 끊기지 않고 부드럽게 움직인다. (정량 기준은 미정)
- **N-06 로직 분리**: 코인·단계·실패 계산 같은 규칙 로직은 화면 코드(React) 없이 순수 TypeScript로 분리한다. 2차 앱 전환을 쉽게 하기 위해서다.
- **N-07 웹 전용 기능 감싸기**: 카메라, 소리, 저장소 같은 웹 전용 기능은 함수 하나로 감싼다.
- **N-08 오프라인**: 서버가 없으므로 인터넷 없이도 동작해야 한다. (가정)
