# 서비스 기획

앱 이름은 아직 정하지 않았다. 화면 레이아웃과 시간순 흐름은 `docs/유저저니.md`에 있다. 이 문서는 "무엇을, 어떤 규칙으로"를 정한다.

표시 규칙: **(가정)** = 사용자가 말하지 않아 정리하면서 정한 것, **(미정)** = 아직 답을 받지 못한 것. 표시가 없으면 사용자가 직접 정한 내용이다.

## 1. 서비스 개요

한 줄 소개: 어릴 적 칭찬 스티커를, 캐릭터가 지켜보고 반응하는 게임 같은 앱으로 옮긴 서비스

- 대상: 5~8세 아이와 그 부모
- 핵심: 부모가 정한 생활습관 미션을 아이가 사진이나 영상으로 인증하면, 길 위의 캐릭터가 한 칸씩 나아간다. 부모가 인증을 확인하면 칸이 확정되고, 챕터가 끝나는 곳의 보물상자에서 부모가 약속한 보상을 받는다.
- 가장 중요한 것
  - 인증하는 순간 캐릭터가 바라보고 반응하는 생동감
  - 길을 따라 올라가는 진행감 (듀오링고의 길, 슈퍼마리오의 "구하러 가는" 느낌. 실제 스토리는 없다)
- 차별점
  - 아이는 인증하자마자 즉시 칭찬(축하 연출)을 받는다.
  - 부모는 사진·영상을 한 건씩 보고 승인한다.
  - 아이가 조작할 것은 최소로 한다. 보상은 신청이 아니라 자동으로 열린다.

## 2. 목표와 단계

| 단계 | 목표 |
|---|---|
| 1차 | 웹앱(PWA)의 완벽한 구현과 시연 |
| 2차 | 1차에 도달하면 Expo Go 형태의 앱 전환을 검토 |

- 시연이 중요하다.
- 2차를 위해 규칙·계산 로직은 화면과 분리해서 만든다. 기술 결정은 `docs/adr.md`에 기록한다 (React + Vite + TypeScript PWA, Supabase).

## 3. 용어

| 용어 | 뜻 |
|---|---|
| 미션 | 부모가 고르는 생활습관. 고정 목록 5개 |
| 인증 | 아이가 미션을 했다는 사진이나 영상 |
| 마디 | 길 위의 동그라미 한 칸. 부모가 승인한 인증 1회가 1마디 |
| 챕터 | 10마디 묶음. 챕터가 바뀌면 배경과 색이 크게 바뀐다 |
| 보물상자 | 챕터의 마지막 마디(10, 20, 30…)에 있는 보상 지점 |
| 보상 | 부모가 챕터마다 정한 선물이나 약속 |
| 확인 대기 | 아이가 인증했지만 부모가 아직 승인하지 않은 상태 |
| 확정 | 부모가 승인한 상태 |

## 4. 핵심 루프

```
        +-------------+
        |  미션 인증  |  사진이나 영상 촬영
        +-------------+
          ^         |
          |         v
+-------------+   +---------------+
|  보상 받기  |   | 한 칸 전진    |  즉시 축하 연출, 확인 대기
+-------------+   +---------------+
          ^         |
          |         v
        +-------------+
        |  부모 승인  |  확정, 상자까지 한 칸 더 가까이
        +-------------+
```

## 5. 미션

고정 목록 5개다. 자유 입력은 없다. 부모는 "미션 만들기"에서 이 목록 중 쓸 것을 고른다.

| 미션 | 인증 방식 | 영상 길이 |
|---|---|---|
| 손씻기 | 영상 | 부모가 10~30초로 설정 |
| 양치하기 | 영상 | 부모가 10~30초로 설정 |
| 비타민 먹기 | 사진 | 해당 없음 |
| 책읽기 | 사진 | 해당 없음 |
| 준비물 챙기기 | 사진 | 해당 없음 |

- 인증 방식은 미션마다 고정이다. 부모가 바꾸지 않는다.
- 영상은 촬영 화질을 낮춰 용량을 줄인다.
- 같은 미션은 하루에 한 번만 인정한다. 하루 최대 5건이다. 기준은 기기의 현지 자정이다. (가정)
- 반려된 미션은 같은 날 다시 인증할 수 있다. 하루 한 번 인정은 "확인 대기 또는 확정"인 건을 기준으로 센다. (가정)
- 양치 미니게임은 없다.

## 6. 두 기기 구성

- 아이 폰 1대와 부모 폰 1대다.
- 아이 폰에서 찍은 사진·영상을 부모 폰에서 보므로 서버(Supabase)가 필요하다.
- 연결: 부모 폰이 가족을 만들고 가족 코드를 발급한다. 아이 폰에서 이 코드를 입력하면 연결된다. (가정)
- 기기의 역할(아이/부모)은 연결할 때 정해지고 이후 고정된다. (가정)
- 부모 PIN은 아이가 부모 화면에 들어오지 못하게 하는 용도로 유지한다. (가정, 두 기기 구조에서 꼭 필요한지는 미정)
- 푸시 알림은 이번 범위에 없다. 부모 폰은 앱을 열었을 때 대기 건수를 보여준다. (가정)
- 사진·영상은 비공개 저장소에 두고 같은 가족의 기기만 볼 수 있게 한다. (가정)

## 7. 진행 규칙

### 마디와 챕터
- 아이가 인증하면 캐릭터가 즉시 한 마디 전진한다. 그 마디는 "확인 대기"로 표시된다.
- 부모가 승인하면 그 마디가 확정된다.
- 부모가 반려하면 그 마디가 취소되고 캐릭터가 한 마디 내려온다. 문구는 "다시 해보자"처럼 부드럽게 쓴다.
- 한 번 승인한 건은 반려할 수 없다. (가정)
- 10마디마다 챕터가 바뀌고 배경과 색이 크게 바뀐다.
- 캐릭터는 성장하지 않는다. 바뀌는 것은 배경과 색뿐이다.
- 마디 수는 승인된 인증의 누적 횟수다. 보상을 받아도 줄지 않는다. (가정)

### 포인트
- 포인트는 마디 수와 같은 속도로 늘어난다. 모든 미션의 포인트가 같고, 마디 수가 곧 포인트다. (가정, 미션마다 포인트가 다른 안은 미정)
- 아이에게는 숫자를 마디 하나로만 보여준다. (가정)

### 보물상자와 보상
- 모든 챕터의 끝(10, 20, 30…)에 보상이 있다. 부모가 챕터마다 설정한다.
- 상자는 **승인된 마디** 기준으로만 열린다. 아이가 확인 대기 상태로 상자 위치까지 가도, 부모가 승인하기 전에는 닫혀 있다.
- 확인 대기 마디가 상자를 지나가도 막지 않는다. 진행 표시는 계속 올라가고 상자는 닫힌 채 뒤에 남는다. (가정)
- 상자가 열리면 아이에게 축하 연출이 나온다. 아이는 신청하지 않는다.
- 부모가 실제로 보상을 준 뒤 "줬어요"를 누르면 보상이 완료된다. 포인트 차감은 이 시점이다. (가정)
- 챕터에 보상이 설정되어 있지 않을 때 상자가 어떻게 보일지는 (미정)이다.

## 8. 상태 전이

### 인증
```
인증 --> [확인 대기] --부모 승인--> [확정]
              |
              +--부모 반려--> [취소] (캐릭터 한 마디 하강, 같은 날 다시 인증 가능)
```

### 보물상자
```
[닫힘] --승인된 마디가 챕터 끝에 도달--> [열림] --부모 "줬어요"--> [완료]
```

### 아이 화면에서 보이는 마디
```
잠김 --> 확인 대기 --> 완료(확정)
              |
              +--> 취소 (잠김으로 돌아감)
```

## 9. 캐릭터와 연출

- 캐릭터 이미지는 사용자가 ChatGPT로 만든다. 정지 이미지이므로 움직임은 표정·포즈 이미지 교체와 코드(이동, 확대, 흔들림)로 만든다. (가정)
- 필요한 상태: 대기, 촬영 중 바라봄, 제출 후 환호, 확인 기다림, 반려 후 격려, 상자 열림 (가정)
- 인증 화면의 연출 방식은 (미정)이다. 후보는 `docs/유저저니.md` 5장에 있다.
- 아이 화면은 글씨를 줄이고 그림과 큰 버튼 중심으로 만든다. 5~8세라 읽기 어려운 아이가 있다. 음성 안내는 나중에 검토한다. (가정)

## 10. MVP 범위

| 구분 | 포함 | 나중에 |
|---|---|---|
| 공통 | 두 기기 연결(가족 코드), 역할 선택 | 푸시 알림 |
| 아이 | 길 홈, 오늘의 미션, 사진·영상 촬영과 캐릭터 반응, 제출 축하, 챕터 전환, 상자 열림, 반려 안내 | 음성 안내, 캐릭터 꾸미기 |
| 부모 | 가족 만들기, PIN, 홈, 인증 확인(건별), 미션 선택, 보상 설정, 보상 전달("줬어요") | 리포트, 형제 여러 명 |

## 11. 시연 시나리오

폰 2대(또는 브라우저 창 2개)로 한다. 시작 상태는 마디 9까지 승인된 데모용 데이터다. 한 건만 승인되면 챕터 1의 끝(10)에 닿는다. (가정)

1. 아이 폰: 양치하기를 골라 영상을 찍는다. 캐릭터가 지켜보며 반응한다.
2. 제출하면 즉시 축하 연출이 나오고 캐릭터가 한 마디 전진한다. 그 마디는 "확인 대기"다.
3. 부모 폰: 대기 1건이 보인다. 영상을 열어 승인한다.
4. 아이 폰: 10번째 마디가 확정되어 챕터 끝에 닿고, 상자가 열린다.
5. 챕터가 바뀌며 배경이 크게 바뀐다.
6. 부모 폰: "줬어요"를 눌러 보상을 완료한다. 아이 폰에 축하 연출이 나온다.
7. 선택: 반려 흐름을 보여준다. 캐릭터가 한 마디 내려오며 "다시 해보자"가 나온다.

| 부모 "지금 줬어요"로 신청 처리 | 열린 상자에서 "줬어요" |

## 13. 아직 정해지지 않은 것

| 항목 | 제안 |
|---|---|
| 미션마다 포인트가 다른가 | 모두 같게 하고 마디 수를 곧 포인트로 한다 (이 문서의 기본값) |
| 부모 PIN의 필요성 | 부모 화면 진입 보호용으로 유지 |
| 인증 화면에서 캐릭터가 어떻게 반응하는가 | 시연에서 가장 눈에 띄는 한 장면을 정해 거기에 집중 |
| 챕터에 보상이 설정되지 않았을 때 | 부모 홈에 "보상을 정해 주세요"를 표시 |
| 챕터 수와 마지막 챕터 이후 | 시연용으로 3개 이상 준비, 이후는 배경을 반복 |
| 영상 용량 한계 | 구현 전에 Supabase 업로드 제한과 촬영 화질을 시험 |
