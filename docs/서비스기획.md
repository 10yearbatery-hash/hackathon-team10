# 서비스 기획

앱 이름은 아직 정하지 않았다 (임시 이름: "펭귄 모험"). 화면 레이아웃과 시간순 흐름은 `docs/유저저니.md`, 기능 목록과 규칙 번호는 `docs/prd.md`에 있다. 이 문서는 "무엇을, 어떤 규칙으로"를 정하는 기준 문서다.

표기 규칙: **(가정)** = 사용자가 말하지 않아 정리하면서 정한 것, **(미정)** = 아직 답을 받지 못한 것. 표시가 없으면 사용자가 직접 정한 내용이다.

## 1. 서비스 개요

한 줄 소개: 어릴 적 칭찬 스티커를, 캐릭터가 길 위를 올라가며 반응하는 게임 같은 앱으로 옮긴 서비스

- 대상: 5~8세 아이와 그 부모
- 기기: **폰 1대**다. 5~8세 아이가 엄마 폰을 빌려 쓰는 상황이라서, 한 폰 안에서 아이 영역과 부모 영역을 나눈다.
- 핵심: 아이가 생활습관 미션을 사진이나 영상으로 인증하면 파란 펭귄이 길 위를 한 단계 올라가고 코인을 받는다. 부모는 PIN을 입력하고 들어와 인증을 한 건씩 보고 성공·실패를 누른다. 아이는 모은 코인으로 상점에서 선물을 고른다.
- 목표 수준: 듀오링고급의 완성도. 캐릭터가 생동감 있게 움직이고, 클리어와 코인 획득 화면이 재미있어야 한다.
- 가장 중요한 것
  - 인증하는 순간 캐릭터가 바라보고 반응하는 생동감
  - 단계를 따라 올라가는 진행감 (공주를 구하러 가는 여정)
  - 클리어했을 때 기뻐하는 연출과 코인을 얻는 재미
- 차별점
  - 아이는 인증하자마자 즉시 클리어와 코인을 받는다. 부모 확인을 기다리지 않는다.
  - 부모는 하고 싶을 때 인증을 한 건씩 보고, 문제가 있는 것만 "실패"로 돌린다.
  - 아이가 조작할 것은 최소로 한다.

## 2. 목표와 단계

| 단계 | 목표 |
|---|---|
| 1차 | 웹앱(PWA)의 완벽한 구현과 시연 |
| 2차 | 1차에 도달하면 Expo Go 형태의 앱 전환을 검토 |
| 수익 | 월 구독 (미션 추가와 20단계 이후). 이번 시연은 결제 화면만 만든다 |

- 시연이 중요하다. 시연은 **온보딩과 1단계**를 중심으로 한다.
- 2차를 위해 규칙·계산 로직은 화면과 분리해서 만든다. 기술 결정은 `docs/adr.md`에 기록한다.

## 3. 용어

| 용어 | 뜻 |
|---|---|
| 단계 | 길 위의 동그라미 한 칸. 하루에 한 단계씩 진행한다. 1~100단계 |
| 장 | 10단계 묶음. 모두 10장이다. 장마다 이름과 배경이 다르다 |
| 미션 | 부모가 고른 생활습관. 한 단계 안에 1개 이상 들어간다 |
| 인증 | 아이가 미션을 했다는 사진이나 영상 |
| 클리어 | 인증을 제출한 상태. 부모 확인 전에도 클리어로 친다 |
| 코인 | 미션을 클리어하면 받는 포인트. 상점에서 쓴다 |
| 선물 | 상점에서 코인으로 고르는 보상. 부모가 실제로 준다 |
| 성공 / 실패 | 부모가 인증을 확인하고 누르는 두 버튼. 성공이 기본 상태다 |
| 부모 영역 | PIN을 입력해야 들어갈 수 있는 화면 묶음 |

## 4. 세계관

- 주인공 파란 펭귄과 분홍 펭귄(공주)이 눈 덮인 마을에서 놀고 있었다.
- 흰 여우(악당)가 포털에서 나타나 분홍 펭귄을 비눗방울에 가둬 보라색 성으로 데려간다.
- 파란 펭귄이 100단계의 길을 올라가 공주를 구하러 간다.
- 이 이야기는 온보딩 영상(10초, 소리 포함)으로 보여준다. 이후 화면에서는 길 끝의 성과 갇힌 공주로 목표를 보여준다.
- 캐릭터는 성장하지 않는다. 바뀌는 것은 배경과 색이다.

| 캐릭터 | 역할 |
|---|---|
| 파란 펭귄 | 주인공. 아이가 길 위에서 움직인다 |
| 분홍 펭귄 | 공주. 100단계 끝에서 기다린다 |
| 흰 여우 | 악당. 납치 장면에 나온다 |

## 5. 핵심 루프

```
+-----------+     +--------------+     +--------------+
| 미션 인증 | --> | 즉시 클리어  | --> | 코인 +10     |
| 사진/영상 |     | 캐릭터 기뻐함|     | 단계 오름    |
+-----------+     +--------------+     +--------------+
      ^                                       |
      |                                       v
+-----------+     +--------------+     +--------------+
| 선물 받기 | <-- | 상점에서 고름| <-- | 코인 모으기  |
+-----------+     +--------------+     +--------------+

 (부모는 원할 때 인증을 열어 성공/실패를 누른다.
  실패하면 캐릭터가 한 단계 내려가고 코인 10을 되돌려 받는다.)
```

## 6. 길과 단계

- 길은 1~100단계이고, 10단계마다 1장이 끝난다 (모두 10장). 장 이름과 배경은 사용자가 정한다. (미정)
- 하루에 **한 단계**씩 진행한다. 한 단계 안에 미션이 여러 개면 **전부 클리어해야** 다음 단계로 올라간다.
- 앞으로 갈 단계는 잠겨 있다.
- 단계를 누르면 그날의 미션 목록이 나오고, 미션을 하나씩 눌러 하고 깨고 다시 누르고 깬다.
- 오늘 단계를 다 깨면 "내일 만나자" 상태가 되고, 다음 단계는 기기의 현지 자정에 열린다. (가정)
- 하루를 못 한 날은 그 단계에 그대로 남는다. 날짜가 지나도 단계가 저절로 올라가지 않는다. (가정)
- 이미 지난 단계를 다시 눌러 볼 수 있는지는 정하지 않았다. (미정)

## 7. 미션

기본 미션은 5개다. 이번 버전에서는 부모가 새 미션을 직접 쓸 수 없다. (직접 만들기는 나중 기능이고 발표에서 말로 설명한다.)

| 미션 | 인증 방식 | 영상 길이 |
|---|---|---|
| 손씻기 | 영상 | 부모가 5~30초로 설정 |
| 양치하기 | 영상 | 부모가 5~30초로 설정 |
| 비타민 먹기 | 사진 | 해당 없음 |
| 책읽기 | 사진 | 해당 없음 |
| 준비물 챙기기 | 사진 | 해당 없음 |

- 인증 방식은 미션마다 고정이다.
- 영상은 화질이 낮아도 된다. 용량을 줄이는 쪽을 우선한다.
- 인증 없이 "했어요"만 누르는 방식은 없다. 인증을 마쳐야 제출 버튼이 켜진다.
- 영상 미션은 부모가 정한 길이를 끝까지 찍어야 제출 버튼이 켜진다. (가정)
- 무료는 미션 1개다. 미션을 더 추가하면 한 단계 안의 미션이 늘어나고, 이 기능이 유료다.

## 8. 코인과 상점

- 미션 1건을 클리어할 때마다 **10코인**을 받는다.
- 상점에는 기본 선물 4개가 있고 부모가 이름과 가격을 수정할 수 있다.

| 기본 선물 (이름은 가정) | 가격 |
|---|---|
| 가족 영화 보기 | 50 |
| 저녁 메뉴 고르기 | 100 |
| 특별 놀이 20분 | 150 |
| 주말 공원 고르기 | 200 |

- 아이가 선물을 고르면 코인이 **바로** 빠진다. 코인이 가격보다 적으면 "코인이 조금 더 필요해"가 나오고 사지 못한다.
- 구매한 선물은 부모의 "구매한 선물" 목록에 쌓인다. 부모가 실제로 선물을 준 뒤 "줬어요"를 누르면 완료된다.
- 코인이 들어오고 나간 내역을 보는 화면은 없다.
- 코인은 마이너스가 될 수 있다. (이미 쓴 코인이 나중에 실패 처리로 회수되는 경우)

## 9. 부모 확인

- 부모는 아이 탭이 아닌 "부모" 탭에서 PIN 4자리를 입력해야 들어간다.
- 인증은 **한 건씩** 넘기며 보고 "성공" 또는 "실패"를 누른다.
- 아이가 인증한 순간 이미 클리어이므로, 부모가 확인하지 않아도 아이의 진행은 유지된다. 부모는 반드시 확인한다는 전제이고 기한은 없다.
- **성공**: 변화가 없다. 그 건은 목록에서 사라진다.
- **실패**: 캐릭터가 **한 단계** 내려가고 코인 10을 되돌려 받는다. 실패한 미션은 지금 단계의 목록에 "다시 해보자"로 올라와 다시 할 수 있고, 다시 성공하면 10코인을 다시 받는다. (가정)
- 실패 문구는 "다시 해보자"처럼 부드럽게 쓴다. 캐릭터는 슬퍼하지 않고 응원한다. (가정)
- PIN을 잊어버렸을 때의 복구는 이번 범위에 없다.

## 10. 유료 (월 구독)

- 무료: 미션 1개, 1~20단계
- 유료: 미션 추가, 20단계 이후
- 결제는 실제로 붙이지 않는다. "이렇게 결제를 만들 것이다"를 보여주는 구독 안내 화면과 가짜 결제 화면만 만든다.
- 가격은 정하지 않았다. (미정)
- 가짜 결제를 마치면 구독 상태가 켜지고 제한이 풀린다. (가정)

## 11. 한 폰 구성

- 아래 탭은 **홈 / 상점 / 부모** 세 개다.
- 홈과 상점이 아이 영역이고, 부모 탭을 누르면 PIN 입력 후 부모 영역으로 들어간다.
- 부모 영역에서 아이 영역으로 돌아오는 버튼이 있다.
- 처음 한 번은 온보딩을 거친다. 이후에는 앱을 열면 홈이 바로 나온다.
- 푸시 알림은 이번 범위에 없다.
- 서버 없이 폰 안에 저장한다. (`docs/adr.md` ADR-003)

## 12. 상태 전이

### 인증 (미션 1건)
```
인증 제출 --> [클리어] --부모 성공--> [확정]
                |
                +--부모 실패--> [취소] (캐릭터 한 단계 하강, 코인 -10,
                                 지금 단계 목록에 "다시 해보자")
```

### 하루 단계
```
[오늘 미션 있음] --전부 클리어--> [내일 만나자] --자정--> 다음 [오늘 미션 있음]
```

### 선물
```
[상점에 있음] --아이가 구매(코인 즉시 차감)--> [구매함] --부모 "줬어요"--> [완료]
```

## 13. 캐릭터, 연출, 소리

- 촬영 화면의 "지켜보는 칸"은 **영상**이다. 파란 펭귄이 두리번거리는 영상이 위에서 아이를 쳐다본다.
- 홈의 길, 클리어 기쁨, 코인 획득, 하강, 장 전환은 **전신 투명 이미지 + 코드 움직임**으로 만든다. Rive(부위별 움직임)는 시간이 남으면 주인공 한 명으로 먼저 시험한다.
- 필요한 캐릭터 상태: 대기, 촬영 중 바라봄, 클리어 환호, 걸어 올라감, 실패 후 응원, 내일 만나자(쉼)
- 소리: 온보딩 영상에는 소리가 있다. 클리어와 스테이지 클리어에는 효과음이 필요하다. 음성 안내는 나중에 검토한다.
- 아이 화면은 글씨를 줄이고 그림과 큰 버튼 중심으로 만든다. 5~8세라 읽기 어려운 아이가 있다.

## 14. MVP 범위

| 구분 | 포함 | 나중에 |
|---|---|---|
| 온보딩 | 시작, 영상, 하강 연출, PIN·이름·미션 설정, 첫 미션과 1단계 클리어 | |
| 아이 | 길 홈, 단계 팝업, 사진·영상 촬영과 캐릭터 반응, 클리어·코인 연출, 하강 안내, 상점과 구매 | 장 전환 연출, 20단계 이후, 음성 안내, 캐릭터 꾸미기 |
| 부모 | PIN, 홈, 인증 확인(건별), 구매한 선물 확인, 미션 관리, 선물 관리, 구독 안내(가짜 결제) | 직접 쓰는 미션, 리포트, 아이 여러 명, PIN 복구 |

## 15. 시연 시나리오

폰 1대로 한다. 시작 상태는 앱을 처음 여는 빈 상태다. 시연은 1단계만 보여준다.

1. 시작 화면에서 "시작"을 누르면 온보딩 영상이 나온다.
2. 카메라가 100단계에서 1단계로 내려온다.
3. 부모가 PIN, 아이 이름, 미션 1개를 정한다.
4. 아이와 같이 첫 미션을 찍는다. 캐릭터가 위에서 지켜본다.
5. 제출하면 기뻐하는 연출과 함께 10코인을 받는다.
6. 연습 미션 클리어(+10코인). 홈에서 1일 발판에 서 있고, 아이가 혼자 1일 미션을 해서 2단계로 올라간다. (ADR-014)
7. 상점에서 선물을 눌러 "코인이 조금 더 필요해"가 나오는 것을 보여준다.
8. 부모 탭에서 PIN을 입력하고 인증을 보고 "실패"를 누른다. 캐릭터가 1단계로 내려오고 "다시 해보자"가 나온다. (가정: 온보딩 첫 미션이 확인 대기에 쌓임)
9. 미션 관리와 구독 안내 화면을 보여주며 "이렇게 결제를 만들 것"이라고 설명한다.
10. 말로 설명: 직접 쓰는 미션, 20단계 이후 유료, 10장 100단계.

## 16. 기존 기획에서 바뀐 점

| 기존 (폰 2대 구조) | 지금 |
|---|---|
| 아이 폰과 부모 폰 2대, 서버, 가족 코드 | 폰 1대, 아이 영역과 부모 영역을 PIN으로 나눔 |
| 마디(10마디 = 1챕터), 보물상자 | 단계(10단계 = 1장, 100단계), 코인과 상점 |
| 부모가 승인해야 확정 | 아이가 제출하면 바로 클리어, 부모는 실패만 돌림 |
| 챕터마다 부모가 보상 설정 | 상점의 기본 선물 4개를 부모가 수정 |
| 한 미션 = 한 마디 | 하루 한 단계 = 그날의 미션 전부 |
| 포인트는 마디 수와 같음 | 미션 1건 = 10코인. 상점에서 쓰고 실패하면 회수 |
| 미션 고정 5개 중 선택 | 기본 5개, 무료는 1개, 추가는 유료 |
