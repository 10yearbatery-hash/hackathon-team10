# 캐릭터 에셋 기록

캐릭터와 관련 이미지, 영상의 출처와 만든 방법을 기록한다. 새 파일을 추가하면 아래 표에 한 줄을 추가한다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `source/` | 사람이 만든 원본 그림 (PNG). 수정하지 않는다 |
| `cutout/` | 원본에서 배경을 지운 투명 PNG |
| `svg/` | 부위별 SVG와 합친 SVG |
| `generated/` | AI로 새로 만든 이미지 |
| `video/` | AI로 만든 영상 원본과 투명 변환본 |
| `previews/` | 원본과 결과물을 나란히 놓은 비교 이미지 |

## 파일 기록

| 파일 | 만든 방법 | 원본 또는 프롬프트 | 날짜 | 비고 |
|---|---|---|---|---|
| `source/hero_penguin_sheet.png` | 사용자 제공 | 파란 펭귄(주인공). 전신 1개와 얼굴 컷 2개가 한 장에 있음 | 2026-10-31 | 채팅 첨부 사본이라 배경이 흰색(불투명). 원본 파일은 따로 확인 필요 |
| `source/heroine_penguin.png` | 사용자 제공 | 분홍 펭귄(여자 주인공). 리본, 인사하는 자세 | 2026-10-31 | 채팅 첨부 사본이라 배경이 검정(불투명). 원본에는 투명일 수 있음 |
| `source/villain_fox.png` | 사용자 제공 | 흰 여우(악당). 보라 망토, 비스듬한 자세 | 2026-10-31 | 채팅 첨부 사본이라 배경이 검정(불투명). 원본에는 투명일 수 있음 |

## 그림체 기준

새 이미지를 만들 때 지킬 조건. 원본 캐릭터를 참고 이미지로 함께 넣는다.
