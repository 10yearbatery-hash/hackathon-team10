# 개발 계획

- 작업 단위는 Phase다. 한 Phase는 `claude -p` 세션 하나가 처음부터 끝까지 맡는다.
- Phase 안의 작업 순서는 세션이 정한다. 이 문서는 목표와 범위만, `plan/acceptance.json`은 완료 기준만 정한다.
- Phase 완료 = 그 Phase의 수용 기준이 모두 `passes: true` + 검증 명령 통과 + 리뷰 `VERDICT: PASS`.
- 진행 상태는 `plan/acceptance.json`, `progress/handoff.md`, `progress/reviews/phase-N.md`에서 본다. 이 문서에는 상태를 적지 않는다.
- 실행 방법은 `harness/README.md`.

(Phase 순서와 의존 관계를 한두 줄로 적는다)
